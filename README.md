# Dispatch — เครื่องมือจำลองและวัดผลการจัดตารางเวลาของ CPU (CPU Scheduling Bench)

**Dispatch** เป็นเครื่องมือจำลองการทำงานของการจัดตารางเวลา CPU (CPU Scheduling Simulator) แบบโต้ตอบ ทำงานบนเว็บเบราว์เซอร์ พัฒนาขึ้นเพื่อช่วยให้เห็นภาพและประเมินประสิทธิภาพของอัลกอริทึมการจัดตารางเวลา CPU ยอดนิยม คุณสามารถป้อนข้อมูลภาระงาน (Workload) ของโปรเซสด้วยตัวเอง หรือเลือกจากชุดข้อมูลตัวอย่างคลาสสิก แล้วสลับไปมาระหว่าง **โหมดเดี่ยว (Single)** เพื่อดูการทำงานของนโยบายที่เลือกผ่านแผนภูมิ Gantt Chart แบบเล่นได้ทีละขั้น กับ **โหมดเปรียบเทียบ (Compare)** ที่รันทุกนโยบายบนภาระงานเดียวกันพร้อมแนะนำนโยบายที่ดีที่สุดโดยรวม — คำนวณทั้งหมดแบบเรียลไทม์ในเครื่องของคุณ

## 🌟 คุณสมบัติเด่น (Key Features)

* **รองรับ 6 นโยบายการจัดตารางเวลา (Scheduling Policies):**
  * **FCFS** (First-Come, First-Served) — มาก่อน ได้รับบริการก่อน
  * **SJF** (Shortest Job First — Non-preemptive) — งานสั้นที่สุดได้ทำก่อน (ห้ามแทรกกลางคัน)
  * **SRTF** (Shortest Remaining Time First — Preemptive SJF) — งานที่เหลือเวลาน้อยที่สุดได้ทำก่อน (แทรกกลางคันได้)
  * **Priority (Non-preemptive)** — จัดลำดับตามความสำคัญ (ห้ามแทรกกลางคัน)
  * **Priority (Preemptive)** — จัดลำดับตามความสำคัญ (แทรกกลางคันได้)
  * **Round Robin** — ผลัดกันทำงานตามช่วงเวลาที่กำหนด (Time Quantum)

* **โหมดเดี่ยว (Single):** แผนภูมิ **Gantt Chart** แบบโต้ตอบพร้อม Tooltip, ปุ่ม **Play / Pause / Step** เล่นการจำลองเวลาทีละขั้น หัวเล่น (Playhead) เผยแผนภูมิตามเวลาจริง และระหว่างเล่นจะมี **ธง ST/CT ปักบนไม้บรรทัดเวลา (Ruler)** บอกตำแหน่งเวลาเริ่มทำงานครั้งแรกและเวลาเสร็จสิ้นของโปรเซสที่กำลังรันอยู่
* **โหมดเปรียบเทียบ (Compare):** รันทั้ง 6 นโยบายบนภาระงานเดียวกัน แสดงเป็น Mini-Gantt หรือตารางสรุปได้ โดยแต่ละคอลัมน์ระบุ **ค่าดีที่สุดด้วยสีเขียว** และ **ค่าแย่ที่สุดด้วยสีแดง** พร้อมไทล์สรุปหัวข้อ (Best-of tiles) และ **แบนเนอร์แนะนำนโยบายที่ดีที่สุดโดยรวม (★ Best overall)** พร้อมคะแนนประกอบ
* **ไทล์สถิติสรุป (Stat tiles):** แสดงค่าเฉลี่ย Turnaround / Waiting / Response และ % CPU ที่ทำงาน เป็นตัวเลขใหญ่อ่านง่ายทั้งในโหมดเดี่ยวและโหมดเปรียบเทียบ
* **ฟังก์ชันการจำลองระดับสูง:**
  * กำหนดเวลาสูญเสียจากการสลับบริบท (**Context Switch**) ได้ — คิดค่าเฉพาะช่วงที่สลับระหว่างโปรเซสคนละตัวที่ต่อเนื่องกัน (ช่วง CPU ว่างไม่คิดค่า)
  * คำนวณค่าเมตริกละเอียดแยกตามโปรเซส: เวลาเริ่มต้น (**Start Time**), เวลาเสร็จสิ้น (**Completion Time**), เวลาวนรอบ (**Turnaround Time**), เวลาการรอ (**Waiting Time**), และเวลาตอบสนอง (**Response Time**)
* **จำการตั้งค่าไว้:** ธีม Light/Dark และโหมดที่เลือกไว้ (Single/Compare) ถูกจดจำไว้ใน `localStorage` สำหรับครั้งถัดไป
* **ไม่ต้องมี Dependencies เพิ่มเติม:** เขียนด้วย HTML5, CSS3 และ JavaScript (ES6+) แท้ๆ ทำงานบน Web Browser ทั้งหมดโดยไม่ต้องพึ่งพาเซิร์ฟเวอร์
* **รองรับการทำงานบน Node.js:** ตัวประมวลผลอัลกอริทึม (`engine.js`) ถูกออกแบบให้แยกออกจากส่วนแสดงผล (DOM) จึงสามารถนำไปรันหรือเขียน Unit Test บน Node.js ได้ทันที

## 📐 สูตรคำนวณค่าเมตริก (Mathematical Formulas)

กำหนดให้:
* $AT$ คือ เวลาที่มาถึง (Arrival Time)
* $BT$ คือ เวลาที่ใช้ประมวลผล (Burst Time)
* $CT$ คือ เวลาที่ทำงานเสร็จสิ้น (Completion Time)
* $ST$ คือ เวลาที่เริ่มทำงานครั้งแรก (Start Time)

สูตรคำนวณพื้นฐานมีดังนี้:

* **Turnaround Time ($TAT$):** 
  $$TAT = CT - AT$$

* **Waiting Time ($WT$):** 
  $$WT = TAT - BT$$

* **Response Time ($RT$):** 
  $$RT = ST - AT$$

* **CPU Utilization ($U$):** 
  $$U = \frac{\sum BT}{\text{Total Time}}$$

### คะแนนแนะนำนโยบายที่ดีที่สุดโดยรวม (Best Overall Score)

โหมดเปรียบเทียบจะให้คะแนนแต่ละนโยบายจากค่าเฉลี่ยของอัตราส่วนระหว่างค่าจริงกับค่าที่ดีที่สุดของคอลัมน์นั้น ($v_k / \min_k$) บน 4 ค่าหลัก ได้แก่ Avg Waiting, Avg Turnaround, Avg Response และ Total Time:

$$S = \frac{1}{4}\sum_{k \in \{WT_{avg},\ TAT_{avg},\ RT_{avg},\ T_{total}\}} \frac{v_k}{\min(v_k)}$$

* $S = 1.00$ หมายถึง นโยบายนั้น **กวาดชนะทุกคอลัมน์** (Clean sweep)
* คะแนนยิ่งต่ำยิ่งดี — นโยบายที่ได้คะแนนต่ำสุดจะถูกแนะนำเป็น ★ Best overall
* กรณีคะแนนเท่ากัน ระบบจะเลือกนโยบายที่อยู่ลำดับก่อนหน้าเป็นแบบ deterministically
* หมายเหตุ: % CPU busy และจำนวน Context switch ไม่ได้ถูกนับในคะแนน เพราะเป็นค่าที่สอดคล้องกับ 4 ค่าข้างต้นอยู่แล้ว (Utilization เป็นส่วนกลับของ Total Time และจำนวน Switch มักสัมพันธ์กับการ Preempt)

## 🚀 วิธีการติดตั้งและรัน (Quick Start)

2. เปิดไฟล์ `index.html` บน Web Browser (เช่น Chrome, Firefox, Edge, Safari) ไ้ทันที ไม่ต้องมีเซิร์ฟเวอร์หรือ Build step ใดๆ

```bash

```

## 📖 คู่มือการใช้งาน (Usage Guide)

หน้าเว็บแบ่งเป็น 3 ส่วนหลัก: **แถบด้านซ้าย (Rail)** สำหรับป้อนข้อมูล, **เวทีกลาง (Stage)** สำหรับแสดงผล และ **แถบบนสุด** สำหรับสลับธีมสี

### 1. ป้อนภาระงาน (Workload) — แถบด้านซ้าย

* **ตาราง Processes:** ป้อนค่าในแต่ละแถว:
  * **Pid** — ชื่อ/หมายเลขโปรเซส (แก้ได้อิสระ)
  * **Arrival** — เวลาที่โปรเซสมาถึง (≥ 0)
  * **Burst** — เวลาที่ต้องใช้ประมวลผล (≥ 1)
  * **Priority** — ความสำคัญ (**ตัวเลขน้อย = สำคัญมากกว่า**)
* ปุ่ม **×** ท้ายแถวเพื่อลบโปรเซส, ปุ่ม **Add process** เพื่อเพิ่ม (รองรับสูงสุด 8 โปรเซส), และปุ่ม **Random workload** เพื่อสุ่มชุดข้อมูลใหม่
* ทุกการแก้ไขจะ **คำนวณใหม่ทันทีแบบเรียลไทม์** ถ้ากรอกค่าไม่ถูกต้อง ช่องนั้นจะขึ้นกรอบสีแดงและระบบจะใช้ค่าเดิมที่ถูกต้องไปก่อน
* **Parameters:**
  * **Quantum** — แสดงเฉพาะตอนเลือก Round Robin
  * **Context switch** — ต้นทุนเวลาเมื่อสลับโปรเซสคนละตัวที่ต่อเนื่องกัน (ค่า 0 = ไม่คิดต้นทุน)
  * **Preemptive priority** — ตัวเลือกให้ Priority แทรกงานที่กำลังรันได้ (แสดงเฉพาะตอนเลือก Priority)
* **Try a classic:** ชุดข้อมูลตัวอย่างคลาสสิก 4 ชุด เช่น "The convoy effect" (โชว์ปัญหางานยาวกั้นคิว) และ "Textbook classic" — กดแล้วระบบจะโหลดข้อมูลและเล่นการจำลองให้ดูทันที

### 2. สลับโหมด — มุมขวาบนของเวที

แถบด้านบนของเวทีมีปุ่มสลับ **Single** (ดูนโยบายเดียว) กับ **Compare all** (เทียบทุกนโยบาย) และมี **ชิปสรุปภาระงาน** เช่น `4 procs · Σburst 18 · q 2 · ctx 0` แสดงภาพรวมข้อมูลปัจจุบันตลอดเวลา — โหมดที่เลือกไว้จะถูกจดจำไว้ในครั้งถัดไป

### 3. โหมดเดี่ยว (Single)

* **แท็บนโยบาย** (FCFS / SJF / SRTF / Priority / Round robin) พร้อมคำอธิบายสั้นของแต่ละนโยบายใต้แท็บ
* **Gantt Chart:**
  * **Play** เล่นการจำลอง (ความเร็วปรับตามความยาวงานอัตโนมัติ), **Pause** หยุดชั่วคราว, **Step** เดินทีละเหตุการณ์ (ขอบเขตของแต่ละช่วงงาน)
  * ระหว่างเล่น หัวเล่น (Playhead) จะเผยแผนภูมิตามเวลา และแสดง **ธง ST (เวลาเริ่มแรก) และ CT (เวลาเสร็จ) บนไม้บรรทัดเวลาใต้แผนภูมิ** ของโปรเซสที่กำลังรัน
  * ช่อง **CPU** ด้านซ้ายบนบอกว่าขณะนั้น CPU กำลังรันโปรเซสใด / ว่าง (idle) / กำลังสลับบริบท (switching)
  * เอาเมาส์ชี้ (หรือกด Tab เพื่อโฟกัส) แต่ละช่วงงานเพื่อดู Tooltip รายละเอียดว่าโปรเซสใดรันช่วงเวลาใด
* **ไทล์สรุป:** Avg Turnaround / Avg Waiting / Avg Response / CPU busy เป็นตัวเลขใหญ่
* **ตาราง Per-process metrics:** ค่า ST, CT, TAT, WT, RT ของทุกโปรเซส พร้อมแถว Average ด้านล่าง

### 4. โหมดเปรียบเทียบ (Compare all)

* **แบนเนอร์ ★ Best overall:** แนะนำนโยบายที่ดีที่สุดโดยรวมพร้อมคะแนน (ดูสูตรด้านบน — 1.00 คือกวาดทุกคอลัมน์)
* **ไทล์ Best-of:** ฝั่งซ้ายบอกว่านโยบายใดชนะแต่ละเมตริก (Avg Waiting / Turnaround / Response / Total time)
* **มุมมอง Gantt:** Mini-Gantt ของทั้ง 6 นโยบายจัดเรียงบนสเกลเวลาเดียวกันเพื่อเทียบกันอย่างเป็นธรรม แถวที่กำลังเลือกอยู่มีข้อความ "· running"
* **มุมมอง Table:** ตารางสรุปทุกค่าเฉลี่ย — **สีเขียว = ค่าดีที่สุดของคอลัมน์, สีแดง = ค่าแย่ที่สุด** (คอลัมน์ CPU busy กลับด้าน: ยิ่งสูงยิ่งดี) หากทุกนโยบายมีค่าเท่ากันคอลัมน์นั้นจะไม่มีสี และแถวที่แนะนำจะมีป้าย **★ best**
* **คลิกแถวหรือเลนใดก็ได้** เพื่อเปิดนโยบายนั้นในโหมดเดี่ยวทันที

### 5. ธีมสี

ปุ่มพระจันทร์/ดวงอาทิตย์ มุมขวาบนสุดเพื่อสลับ Light/Dark (ระบบจะตามธีมของ OS โดยอัตโนมัติจนกว่าจะกำหนดเอง และจำค่าที่เลือกไว้)

node test.js
